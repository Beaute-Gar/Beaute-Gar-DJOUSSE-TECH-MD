Installation

  1. Télécharge l'APK puis ouvre-le.
  2. Autorise l'installation depuis cette source si Android le demande.
  3. Ouvre l'appli, accepte l'avertissement, autorise l'exécution en arrière-plan.
  4. Saisis ton numéro, copie le code, entre-le dans WhatsApp (Appareils connectés).

Connexion WhatsApp non officielle : ton numéro peut être limité ou banni. Utilise de préférence un numéro secondaire.
